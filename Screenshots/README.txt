## How to Take Each Screenshot

1. Open VS Code with the GitHub Copilot extension installed
2. Open Copilot Chat (Ctrl+Alt+I  or  View > Copilot Chat)
3. Copy the prompt from the matching .txt file above
4. Paste into Copilot Chat and press Enter
5. Take a screenshot showing BOTH your prompt AND Copilot's response
6. Save as the .png filename in the table above (e.g., copilot_testing_framework.png)
7. Save the file in THIS Screenshots/ folder
